# 🐱 เสื้อสีไรดีเหมียว

เว็บดูสีเสื้อมงคลประจำวันสำหรับมือถือ แมวหมอดูจะเปิดตำราทักษาแล้วใส่เสื้อสีตามผลให้ดู **เพื่อความบันเทิงเท่านั้น**

## วิธีใช้
1. กด **เริ่มดูดวง**
2. เลือกวันเกิด (มี 8 ตัวเลือก โดยแยกพุธกลางวันกับพุธกลางคืน ซึ่งนับตั้งแต่ 18:00 น.)
3. เลือกเรื่องที่อยากเสริม: การงาน / การเงิน / สุขภาพ / ผู้ใหญ่เมตตา / เสน่ห์ คนรอบข้าง
4. ดูผล: สีเสื้อหลัก, สีเสริม (กระเป๋าหรือของใช้), สีที่ควรเลี่ยง และคำทำนายขำ ๆ จากแมว
5. สลับดู **วันนี้ / พรุ่งนี้** ได้ กด **คัดลอกคำทำนาย** ไปแปะใน LINE ได้ หรือกลับไปหน้าแรกเพื่อเริ่มใหม่

## กติกา
- ผลขึ้นกับ 3 อย่าง คือ วันเกิด, วันที่จะใส่ และเรื่องที่อยากเสริม
- **ใส่ข้อมูลเดิมในวันเดียวกันจะได้ผลเหมือนเดิมตลอดวัน** วันเปลี่ยนตอนเที่ยงคืนตามเวลาไทย (Asia/Bangkok)
- เว็บจำวันเกิดไว้ใน `localStorage` ของเครื่องนั้นเท่านั้น ไม่ส่งข้อมูลออกไปที่ไหน

## วิธีคำนวณ (หลักทักษา)
- เรียงดาวเป็นวง 8 ดวง: อาทิตย์ → จันทร์ → อังคาร → พุธ → เสาร์ → พฤหัสบดี → ราหู → ศุกร์ ([ศิลปวัฒนธรรม](https://www.silpa-mag.com/?p=150762))
- ดาวของวันเกิดอยู่ภูมิ "บริวาร" ดาวถัดไปตามวงจะได้ภูมิ อายุ, เดช, ศรี, มูละ, อุตสาหะ, มนตรี, กาลกิณี ตามลำดับ ([GotoKnow](https://www.gotoknow.org/posts/386870))
- การจับคู่หมวดกับภูมิ: การงาน = เดช, การเงิน = ศรี, สุขภาพ = อายุ, ผู้ใหญ่เมตตา = มนตรี, เสน่ห์ = บริวาร
- **สีหลัก** คือสีของดาวที่อยู่ภูมินั้นในทักษาวันเกิด
- **สีเสริม** คือสีของดาวที่อยู่ภูมิเดียวกันในทักษาของวันที่จะใส่
- **สีที่ควรเลี่ยง** คือสีกาลกิณีของวันเกิดและของวันที่จะใส่
- ถ้าสีหลักตรงกับกาลกิณีของวันที่จะใส่ เว็บจะสลับไปใช้สีจากทักษาวันนั้นแทน และบอกเหตุผลบนหน้าจอ (เกิดขึ้น 35 กรณีจากทั้งหมด 280)
- สีประจำดาว: อาทิตย์แดง, จันทร์เหลือง, อังคารชมพู, พุธเขียว, พฤหัสส้ม, ศุกร์ฟ้า, เสาร์ม่วง
  - สีราหู (ดำ/เทา) ใช้ตามความเชื่อที่นิยมทั่วไป ยังไม่ได้ยืนยันกับตำรา
- คำทำนายสไตล์ขำ ๆ เขียนโดย AI
